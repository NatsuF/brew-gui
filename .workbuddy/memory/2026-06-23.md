## 修复操作历史加载失败
- 根因：`_get_history_file()` 中 `touch()` 创建空文件，`api_history()` 用 `json.load()` 读取空文件抛出 `JSONDecodeError`（500 错误）
- 修复 `_get_history_file()`：新建文件时写入 `[]` 而非空 touch
- 修复 `api_history()`：增加 `JSONDecodeError` 异常处理，文件损坏时自动重置为空列表
- 重新打包并测试：空状态返回 `{"history":[],"total":0}`，写入后正常读取 3 条记录

## 修复双击 .app 程序坞图标一直跳的问题
- 根因1：`console=False` 模式下 `sys.stderr` 为 `None`，调用 `sys.stderr.isatty()` 抛 `AttributeError`，app 启动即崩溃
- 根因2：macOS 认为 GUI 应用应显示窗口，Flask 无原生窗口，程序坞等待窗口出现导致图标一直跳
- 修复 `app.py`：去掉 `sys.stderr.isatty()` 判断，直接用 `getattr(sys, 'frozen', False)` 检测打包模式，加 try/except 保护日志重定向
- 修复 `brewmaster.spec`：`info_plists` 改为 `info_plist`（单数），添加 `LSUIElement: True`（后台代理应用，不显示程序坞图标）
- 重新打包并测试：`open BrewMaster.app` 启动正常，无程序坞跳动，浏览器自动打开，所有 API 正常
